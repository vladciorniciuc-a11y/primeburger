# Prime Burger România - Website Prezentare & Platformă Franciză

Platformă modernă de prezentare a brandului și achiziție de franciză pentru **Prime Burger România**.

## 🚀 Caracteristici Tehnice & Arhitectură
- **Design Gourmet & B2B Dual Focus:** Orientat atât pe apetit culinar (fotografii burgeri gourmet, schiță tehnică 16:9 blueprint), cât și pe conversia cumpărătorilor/investitorilor de franciză.
- **Hartă Națională Vectorială:** Contur cartografic precis cu toate cele 42 de județe din România, Hub Logistic Central la Dumbrăveni (jud. Suceava) și rute logistice animate.
- **Simulator Subdomeniu Dedicat:** Previzualizare interactivă a magazinului online propriu pentru fiecare franciză (`oras.primeburger.ro`) conectat la WhatsApp cu 0% comision.
- **Configurator de Meniu:** Fereastră pas-cu-pas pentru selectare ingrediente, garnituri, sosuri artizanale și băuturi.
- **Formulare de Lead & Aplicare Franciză:** Descărcare dosar de investiție (PDF) și formular complet de calificare a partenerilor.

## 🛠️ Rulare Locală
Proiectul rulează nativ în orice server web static sau Apache/Nginx (ex: XAMPP).
Accesați `index.html` prin browser sau prin serverul local `http://localhost/primeburger.ro/`.
